# 听背打（网页版）

这是「听背打」的纯静态网页版，可以放在 GitHub Pages 上，用手机或电脑浏览器直接打开。不需要安装 Node、Docker 或数据库，也没有登录账号。进度按家庭成员保存在本机浏览器里（localStorage）。

一家人一起学英语：车上听，在家打。内置 20 课，含生活、入门核心词（人物家庭、食物饮料、常用动作、形容颜色、场所方位、天气服装、身体感觉、学习生活）、基础、出行、办公室、邮件、IT，以及综合里的随机练习和「磨耳朵」。单词和短句都有美式音标和解析。

车上「只听连播」默认开着循环，适合长时间磨耳朵；也可关掉循环。听的时候英文单词下方对着音标。手机浏览器会自动适配屏幕尺寸。

## 在本机预览

请先进入本目录，再用本地网页服务打开（不要直接双击 `index.html`，否则浏览器可能无法加载课程和发音）：

```bash
cd listen-type-pages
python3 -m http.server 8080
```

然后用浏览器打开 http://127.0.0.1:8080 。同一局域网里的手机也可以访问这台电脑的地址，例如 `http://192.168.1.8:8080`。

## 放到 GitHub Pages

把本目录中的全部文件上传到 GitHub 仓库（可以是仓库根目录，也可以是某个子目录）。然后在仓库的 Settings → Pages 里，选择对应分支和目录并保存。

如果仓库名是 `listen-type`，网站地址通常是 `https://你的用户名.github.io/listen-type/`。本站全部使用相对路径，放在子路径下也能打开。

第一次打开时请先连着网络，让课程数据和页面加载完成。之后已缓存的页面可以离线打开；发音按网络加载，听过的文件也可能被浏览器缓存。

默认家庭是「我家」，成员为爸爸、妈妈、孩子，可在家庭页添加成员。每日任务：听 5 句、打对 5 句。开车请只用「只听连播」，打字请交给乘客。

进度只存在当前浏览器中。换设备、换浏览器或清除网站数据后，需要重新开始记录。

线上地址：https://baibibo.github.io/listen-type/
